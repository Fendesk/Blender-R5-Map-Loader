# Blender-R5-Map-Loader
*R5 Map Loader is a Blender add-on that let you open full Apex Legends, R5Flowstate and R5Reloaded maps in Blender.*
**Features:**
- Small Props and Distance Culling
- LOD gen
- Entities importer (dynamic props, ziplines, POIs) *Load .vpk files*
- POI Loader
- Skybox Loader
- De-duplicate textures/materials
